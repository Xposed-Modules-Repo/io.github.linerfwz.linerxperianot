# LinerXperiaNot

监听 `Settings.Global` 中的 `sf_rr_mode_event`，在切换刷新率模式时通过 SystemUI 发送静音顶部弹窗通知，并在 5 秒后自动消失。
listens for the `sf_rr_mode_event` in `Settings.Global`. When the refresh rate mode is switched, it sends a silent top-of-screen notification via SystemUI, which automatically disappears after 5 seconds.

## 特性
- 自动适配中文 / 英文通知与模块描述
- Automatically adapts notifications and module descriptions to Chinese or English
